# 通用表格閱讀器

NVDA 附加元件，辨識網頁上缺少表格語意的規則資料，提供獨立閱讀視窗，或將推測表格整合至原頁的表格導覽。

目前採用版本：**1.0**。限 NVDA 2026.3，使用該版本的內部 API；更新 NVDA 前需要重新驗證相容性。

## 安裝與使用

安裝 `tableReader-1.0.nvda-addon` 並重新啟動 NVDA。在網頁的瀏覽模式按：

- **NVDA＋Ctrl＋Shift＋Y**：建立原頁表格；再次按下可撤除。
- **Ctrl＋Home**，再按 **T**：從頁首尋找表格；**Shift＋T** 尋找上一個表格。
- **Ctrl＋Alt＋方向鍵**：逐格閱讀。
- **NVDA＋Ctrl＋Shift＋T**：開啟獨立表格閱讀視窗。

原頁模式保留網站連結與按鈕的操作，並支援儲存格點字閱讀範圍。推測格內不呈現「可點擊」狀態提示，仍保留角色及其他狀態。

## 限制

- 需手動建立；同時只替一份文件啟用。
- 網頁更新後，原位置及文字仍吻合就保留；文字或位置改變、重新載入時須重建。
- 全文序列核對至少需要四個非空白格，且完整序列必須唯一。僅容許空白差異。
- 沒有可靠文字位置的空白格略過，其他格子的列欄編號不變。原生導覽最多略過三個連續缺格。
- 推測可能將卡片等規則排列辨識為表格，使用時需核對。並非所有網站、瀏覽器或點字操作均已驗證。

## 驗證

54 項自動測試通過，部分測試直接載入 NVDA 2026.3 原始導覽方法，其他依賴以模擬物件測試。
使用者已逐版回報原頁導覽、點字換格同步、離開後返回，以及 0.2.6 空白格情況成功。這些回報不等同所有網站及硬體的完整驗證。

```powershell
python -m unittest discover -s . -p 'test_*.py'
python build.py
```

測試需要將 NVDA `release-2026.3` 原始碼放在專案同層的 `nvda-2026.3-source` 目錄。建置輸出位於 `dist/`，建置程式核對 ZIP 格式、CRC、版本及封裝內容與來源一致性。

發布內容只包含附加元件程式、人工測試資料與說明，不包含使用者匯出的網頁、金鑰、帳號資料或截圖。

通用表格閱讀器 0.2.6-dev 原頁導覽實驗版

0.2.6 容許完整序列中有空白格，仍須至少四個非空白格且完整文字序列唯一。沒有文字位置的空白格略過，保留其他格子原本的列欄編號；連續空白格導覽受 NVDA 原生最多略過三格的限制。

0.2.5 移除推測儲存格內的「可點擊」狀態提示，保留連結、按鈕角色、其他狀態及原網站操作。表格外的提示與 NVDA 全域設定不變。

此版新增對應失敗的診斷視窗，只顯示候選編號、列欄與固定原因代碼，不含網頁文字或金鑰。 容器不能直接對應時，會嘗試其子文字物件；每段及合併後文字都須吻合才接受。

0.2.4 收到網頁更新通知時，先核對表格位置與文字，仍吻合就保留原頁導覽，避免無關更新使表格消失。

0.2.3 修正點字閱讀範圍與換格更新通知。使用者已回報換格同步成功；尚未驗證所有點字操作。

0.2.2 新增整表完整序列對應：物件沒有獨立文字位置時，以已辨識的所有儲存格文字依序組成完整序列， 與 NVDA 緩衝區核對。只容許空白差異，完整序列必須唯一；有額外字元、重複整表或超過 50 萬字元時拒絕。 不逐格猜測、不以金鑰或日期格式切割。UTF-16 位置包含 emoji 的雙碼元換算。

適用目標為 NVDA 2026.3。這是 NVDA 附加元件，不需要 Chrome 擴充功能。

原頁面表格導覽（新增實驗功能）

  1. 安裝此版會更新原本的 tableReader；重新啟動 NVDA。
  2. 開啟網頁，等待資料穩定，將閱讀位置移到網頁內，確認使用瀏覽模式。
  3. 按 NVDA＋Ctrl＋Shift＋Y，等待「已建立」通知。這一步先建立一次原頁對應，不會另開閱讀視窗。
  4. 按 Ctrl＋Home 回頁首，再按 T 找到表格；Shift＋T 回上一個表格。若原先閱讀位置已在表格內，T 會尋找下一個，並不會回到目前表格開頭。
  5. 按 Ctrl＋Alt＋方向鍵逐格移動；Ctrl＋Alt＋Home／End 移至第一／最後欄，Ctrl＋Alt＋PageUp／PageDown 移至第一／最後列。
  6. 再按 NVDA＋Ctrl＋Shift＋Y 可撤除原頁導覽。

離開表格不會撤除對應。頁面更新後，表格在原位置且文字未改變時會保留；表格文字或位置改變、虛擬緩衝區重新載入時，對應會自動撤除，需要再建立。第一階段尚不會每次開網頁就自動辨識。 建立期間請停留在同一分頁；不支援同時替多份文件啟用。最多對應每個候選的 256 格。

只有推測表格且每格文字能與原網頁位置可靠對應時才補入；既有原生表格繼續使用 NVDA 原本的處理。 補入的操作欄標題若沒有實際文字位置，該格不提供跳轉，其他資料列的操作格仍可閱讀。 啟用原頁模式後，連結或按鈕仍留在原網頁，沒有複製或重新實作網站操作。

若確認第一列是標題，可以在輸入手勢中為「實驗：建立原頁表格導覽，並以第一列當欄位標題」另外指定快捷鍵。 只支援 NVDA 2026.3 的虛擬緩衝區；其他版本與不同文件後端會拒絕啟用。未驗證所有朗讀／點字情況。

本版本經使用者允許使用內部 API。遇到問題可先撤除、重新整理網頁或重新啟動 NVDA；也可重新安裝保留的 0.1.0 版本回復。

使用方式

  1. 在網頁使用方向鍵或物件導覽，移到想閱讀的資料附近。
  2. 按 NVDA＋Ctrl＋Shift＋T。掃描中再按一次可取消。
  3. 若找到候選表格，會開啟 NVDA 的瀏覽式訊息視窗。按 T 尋找表格，按 Ctrl＋Alt＋方向鍵逐格閱讀。
  4. 按 Esc 或關閉按鈕返回原頁面。資料更新後請重新執行指令。

在 NVDA「偏好設定 → 輸入手勢 → 通用表格閱讀器」可修改快捷鍵。 另有「以第一列當欄位標題」指令，預設沒有快捷鍵；只有確認第一列確實是標題時才使用。

辨識範圍

優先讀取無障礙表格、列、儲存格角色。對缺少角色但有規則列與位置的物件，提供「依位置推測」結果。 卡片排列也可能被辨識為候選，請核對資料是否對應。沒有已標記欄名時使用「第 1 欄」等名稱，不自行猜測。

上述 NVDA＋Ctrl＋Shift＋T 舊功能仍是文字副本，不修補原頁面的 T 導覽，也不執行原網站按鈕或連結。 只讀取提供者已載入的內容，不能保證取得捲動後才載入的資料。

單一整段文字、圖片表格、合併儲存格、不規則欄位、未暴露的封閉元件可能無法辨識。 不支援直接修正 DOM；不依裝置名稱、日期或金鑰格式拆欄。BitLocker 即時頁面尚未驗證。

效能與隱私

只在手動執行時讀取，分批處理，最多 1800 個物件、40 層及約 8 秒；超限時不呈現不完整結果。 單次系統無障礙 API 若卡住，仍可能超過時間限制。離開目前程式、鎖定畫面或卸載附加元件時停止掃描。 不存檔、不連網、不寫入剪貼簿，不在記錄中寫出網頁文字。密碼、隱藏及編輯欄位略過。

驗證狀態

已依本機 release-2026.3 原始碼與兩份開發指南查證 API。 安裝包版本相容欄位表示此測試版的開發目標，不代表所有功能已完成實機相容驗證。 尚待真正 NVDA 2026.3 + Chrome／Firefox 的安裝、語音、點字、焦點、表格導覽與動態網頁測試。
